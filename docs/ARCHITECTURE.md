# Architecture Baseline

## Stack Target
- Next.js App Router
- React
- TypeScript Strict Mode
- Tailwind CSS
- PWA

## Core Architecture

```
app
 ├── core
 ├── security
 ├── storage
 ├── sync
 ├── input
 └── tests
```

## Security Principles
- Local-first data ownership
- Encryption at rest
- Validated schemas
- Minimal identity exposure
